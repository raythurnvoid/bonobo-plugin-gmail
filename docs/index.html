Bonobo Gmail

A Gmail backup plugin for Bonobo Senate. It copies sent and received emails into ordinary Markdown files in your selected workspace. Attachments are saved beside each email.

Connecting asks only for read-only Gmail access. You connect through Google consent and finish on your original Bonobo Senate page.

The Mail page can also write Gmail drafts, with help from the Bonobo Senate agent. This needs a second step, Allow drafts and Send, which asks Google for the gmail.compose permission. Only the member who connected the account can take it. The agent can write drafts but never send them. Only your Send click sends an email. The plugin never deletes your emails.

Your workspace, your files

Saved mail follows Bonobo Senate Files permissions. People with access to those files can read them. You can search the files and ask a Bonobo Senate agent to read them.

Disconnect stops future sync and clears the plugin's saved Gmail access. Existing files stay until you remove them in Bonobo Senate. Disconnect before uninstalling.

Development status

This integration is being tested. Public release, Google verification, and hosting capacity checks remain open.
